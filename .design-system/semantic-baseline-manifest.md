- Semantic implementation paths are the completed plan’s known package, facade, contract, state-audit, lint, feedback, avatar, settings-pilot, and layout files.
- Durable `.design-system` files are force-added because CI/worktrees require the exact lint baseline and the next migration requires the accepted contracts. Captures, logs, PIDs, temporary scripts, auth state, and registry artifacts remain ignored.
- `.agents/**`, `.claude/**`, `.unipi/**`, `agent/**`, skill lock changes, and unrelated application/backend changes are excluded.
